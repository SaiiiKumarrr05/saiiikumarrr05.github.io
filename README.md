# Saikumar Potturi — Portfolio Website 🚀

A personal portfolio website built with pure HTML, CSS, and Three.js — no frameworks, no build step, no npm.

**Live Site:** [saiiikumarrr05.github.io](https://saiiikumarrr05.github.io/)

---

## Preview

> Dark, high-end aesthetic with a real-time 3D background — floating wireframe polyhedra, orbital rings, star field, and mouse parallax powered by Three.js. Fully responsive with a hamburger nav on mobile.

---

## Tech Stack

| Layer         | Technology                                 |
| ------------- | ------------------------------------------ |
| Structure     | HTML5                                      |
| Styling       | CSS3 (custom properties, animations, grid) |
| 3D Background | Three.js (r128)                            |
| Fonts         | Syne + Space Mono (Google Fonts)           |
| Hosting       | GitHub Pages                               |

---

## Features

- 🌐 **Three.js 3D background** — 20 floating wireframe polyhedra, 3 orbital rings, 400-point star field
- 🖱️ **Custom cursor** with magnetic hover effect (desktop only)
- 📜 **Scroll-triggered reveal animations**
- 🎞️ **Infinite marquee** skills strip
- 📱 **Fully responsive** — hamburger nav, stacked layouts, mobile-safe padding
- ⚡ **Zero dependencies** — no npm, no build tools
- 🔗 **Verified certificate links** on all cert cards

## Getting Started

```bash
git clone https://github.com/SaiiiKumarrr05/saiiikumarrr05.github.io.git
# open index.html in your browser — no server needed
```

---

## Deployment (GitHub Pages)

1. Push `index.html` to the `main` branch
2. Go to **Settings → Pages → Source → main / root**
3. Save — live at `https://saiiikumarrr05.github.io/`
